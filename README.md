# earthwonders2025.github.io
https://earthwonders2025.github.io/

EarthWonders 2025 is an interactive educational web application that dynamically showcases natural and cosmic phenomena through galleries. The frontend is a Single Page Application (SPA) built with HTML, CSS, and JavaScript, hosted on GitHub Pages, while all content is served via a Django REST Framework (DRF) backend. Galleries, images, videos, site settings, and footer texts are delivered as JSON from the API, enabling the site to be fully data-driven and automatically updated whenever new content is added to the backend.

When the site loads, the JavaScript fetches all gallery data from the DRF API. The very first gallery returned from the API is treated as the featured gallery and is displayed prominently at the top of the page with a large hero section, parallax effect, dynamic meta tags, and JSON-LD structured data for SEO. All remaining galleries are rendered below the featured gallery, sorted so that newer items appear first. This ensures that the featured gallery remains consistently at the top while the latest content is easily discoverable.

Each gallery section includes interactive elements. Clicking the “Explore More” button opens an overview modal that contains detailed descriptions, paginated images, and embedded YouTube videos. Images support zooming and drag-to-pan functionality, while video thumbnails open in an iframe with autoplay enabled. Pagination allows users to navigate through multiple images or videos, and the modal supports touch gestures for mobile devices. All modal content is dynamically generated from the API, so updates to galleries, images, or videos appear automatically without any frontend changes.

The site also includes a dynamic navigation bar generated from the gallery list. It highlights the currently visible section on scroll, supports smooth scrolling, and allows swipe or arrow-based navigation on mobile devices. The footer, motivational texts, and favicon are loaded from the backend API as well, maintaining consistent branding across the site.

In summary, EarthWonders 2025 combines a static SPA frontend with a dynamic Django REST Framework backend, featuring a first gallery as the permanent featured section and all other galleries dynamically rendered with the newest content first. This architecture allows the site to remain interactive, visually rich, SEO-friendly, and fully data-driven.
